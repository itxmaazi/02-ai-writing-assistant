# AI Writing Assistant — Setup Guide

## Requirements

- Python 3.14.6
- VS Code with Python extension
- API keys: Gemini (x3), Groq

## Installation

1. Create project folder: `D:\Python\02-ai-writing-assistant`
2. Create virtual environment: `python -m venv .venv`
3. Activate: `.venv\Scripts\activate`
4. Install packages: `pip install streamlit google-genai openai python-dotenv requests`
5. Create `.env` with API keys
6. Create `.gitignore` to protect secrets
7. Run: `streamlit run app.py`
