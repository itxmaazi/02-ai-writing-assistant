# AI Writing Assistant — Feature List

## Phase 1 (Must Have — Build First)

- [ ] Streamlit app with sidebar + main workspace
- [ ] Multi-provider AI engine (Gemini + Groq )
- [ ] Write tool — generate content from a topic
- [ ] Improve tool — enhance existing text
- [ ] Tone changer — switch writing tone
- [ ] Grammar fixer — correct errors
- [ ] Streaming output — text appears word by word
- [ ] Copy to clipboard button
- [ ] Word count / character count / reading time
- [ ] Dark theme

## Phase 2 (Should Have)

- [ ] Rewrite tool
- [ ] Expand tool
- [ ] Shorten tool
- [ ] Summarize tool
- [ ] Translate tool
- [ ] Template system (Blog, Email, Essay, etc.)
- [ ] Multiple output comparison (generate 3 versions)
- [ ] Save/load documents to disk
- [ ] Export to Markdown file
- [ ] History sidebar

## Phase 3 (Nice to Have)

- [ ] Export to DOCX
- [ ] Export to PDF
- [ ] Light theme toggle
- [ ] Writing statistics dashboard
- [ ] Favorite templates
- [ ] Prompt library (save custom prompts)
- [ ] Keyboard shortcuts
- [ ] Real-time grammar underline (like Grammarly)
